# PROLOVE — демо сайту

Статичне демо вітрини PROLOVE («Кава вогонь»): Запитай (Матриця) · Кава (стрічка лотів) · Заварити (комікс-інструкції з таймерами) · Партнерам.

Працює без сервера: дані лотів лежать у `data/`, а запити до API обробляються в браузері (`demo-shim.js`).
Справжні замовлення, рахунки і вхід через Telegram — лише в повній версії на сервері.
